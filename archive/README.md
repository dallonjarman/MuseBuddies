# Archive

## site-v1

The first MuseBuddies website, as it was at commit `8e48294` (PR #21): a light/dark landing page
with the four-chapter phone and relay-cloud hero demo (`demo.js`), the "Try it yourself" playground
(`play.js`), routines, the comparison table, "Under the hood" and the FAQ.

It was replaced by the scroll-driven story site in `public/`. These files are kept for reference
and are not served by the relay or deployed to Pages. To view it, serve this folder with any static
file server (`npx serve archive/site-v1`); `{{PUBLIC_URL}}` and `{{ASSET_VERSION}}` placeholders are
left unfilled.
